# Mech Fighters — памятка для Claude

Коротко: как работать, решения Сани, устройство кода, проверки.
**Подробно о каждой механике** (что сделано, когда, почему, имена функций, замеры) — в `NOTES.md`. Целиком его не читай, ищи по слову (Grep). План и цель по картинке — `ROADMAP.md`, открывай только для визуальных задач.

## Заказчик и правила работы
- Саня, соло-разработчик, **не программист**. По-русски, просто и коротко, без имён функций без нужды.
- Делай только то, что просили. Правь существующие файлы, новые без причины не создавай.
- **Новые сессии/ветки не создавать и не предлагать** — съедают 30–40% лимита. Всё в одном чате. Работать экономно.
- Сначала ответ на вопрос, потом работа. Сломал — скажи, что это ты, и почини.
- **Не меняй внешний вид без спроса.** Ускорение не должно менять картинку.
- Если окно игры всё же нужно — без спроса, но одним запуском без звука после всех правок.
- После законченной работы — коммит и пуш в main (github.com/aleskandrkadomcev/mech_fighters).
- Своих задач не придумывать и не предлагать, ничего не делать «на будущее». Вопрос «почему?» — просьба объяснить, а не задача. Важную проблему — одной строкой в ответе.
- Роль: не только код, но и опытный геймдизайнер — честно спорить, если идея не в видении игры («дота в сайфай», WASD + стрельба по прицелу, игроки 20+; без аниме-ушек и майнкрафта).
- Бесплатные ассеты (CC0/MIT/OFL, CC-BY с автором) качать без спроса; сырые архивы — `assets/incoming/`, готовое — `assets/...`, запись в `assets/CREDITS.txt`. Платное и NC/GPL не брать.
- Кнопки, которые стирают работу Сани (сброс, удаление), — подальше от «Закрыть/Ок» и только с подтверждением.
- `МЕХИправки.txt` и «задачи и идеи.txt» (корень проекта, файлы Сани, в git не добавлять) — **не открывать и не править, пока Саня сам не попросит**. Свои идеи туда не ставить.
- **Снимки экрана и окно игры — только когда без них никак** (проверить картинку, которую нельзя проверить тестом) или Саня просит. Обычно: правка → тест без окна → «готово, проверь сам: что открыть и куда смотреть». Смотреть, как выглядит и как играется, Саня будет сам.

## Решения Сани — не нарушать
- Тени: 4 слоя, 160 м. Дымки (fog) нет. Пресет «Высокие» — задуманный вид.
- Мехи без краски команды; свой/чужой — по полоске здоровья и нику (свой светло-синий, союзник зелёный, враг красный). Постройки, крипы, миникарта — в цветах команд.
- Нет меток, куда упадёт снаряд турели. Нет кругов от взрывов и метки залпа ракет. Нет побеления при попадании.
- Метки (Alt) — без слов, только цвет и значок.
- Разрушаемая мелочь — только декор, без урона; бочек с уроном не делать.
- Не тянуть «единый стиль»: проект инди. Готовые бесплатные ассеты лучше самодельных (они в `assets/`, см. CREDITS).
- Боты новые механики пока не применяют — учить отдельным этапом.

## Игра
Godot 4.7.2, рендер GL Compatibility. Вид сверху под углом, как в доте. PvP-моба на мехах, геймплей плоский (нет высот, только укрытия). Меню → «Играть» (карта, боты, крипы; режим «Моба» или «PvP») → ангар → бой. Есть редактор карт, пауза (Esc), таблица после боя, панель настроек F2 (работает везде).
Карты — `maps/*.json` (формат в начале `maps.gd`): `classic.json` (моба: базы, турели 3 уровней, штаб с ядрами-Теслами, крипы, линии), `arena.json` (PvP).
Мех = шасси (10 шт.) + ядро + 2 пушки (ЛКМ/ПКМ) + модули с абилками (Q E R F C V G X). Пробел — рывок, T — телепорт на базу, B — ангар, H — подсказка, Alt — метки и подсказки к интерфейсу.
Масштаб: 1 единица = 1,48 м (`Cfg.METERS_PER_UNIT`), игра считает в единицах, в F2 и ангаре — метры.

## Тикрейт 30
- Вся игровая логика — в `_physics_process` (30 тиков/с, под онлайн). В `_process` — только вид (интерфейс, камера, твины, эффекты).
- Камера и прицел берут сглаженные между тиками значения (`get_global_transform_interpolated`, `*_smooth` у меха).
- После телепорта/новой модели — `Mech.snap_interpolation(узел)`; новые снаряды после установки старта — `reset_physics_interpolation()`. Эффекты на твинах — `physics_interpolation_mode = OFF`.

## Производительность (монитор 144 Гц, кадр 6,9 мс)
- Тяжёлое в тике разносить по тикам или переносить в `_process`, если это картинка.
- Мехи и крипы для поиска целей — из `main.units()`, не перебирать группы.
- Подписи, цвета, рамки, параметры материалов, положение узлов ставить **только при изменении** (`hud.gd`: `_txt`, `_font_col`, `_bg`, `_border`).
- Неподвижные детали склеиваются (`Art.merge_meshes`); деталь, на которую ссылается код, — в список `keep`.
- Туман войны: кто кого видит — на тиках 10 раз/с; веер — в `_process` понемногу. Не собирать фигуру каждый кадр.
- Пресеты графики: `Cfg.gfx(низкие, средние, высокие)`, хранятся в `user://graphics.cfg`.

## Тонкости кода
- Слои столкновений: 1 стены, 2 тела мехов, 4 хитбоксы, 16 обломки и ящики, 32 постройки и декор, 64 крипы, 128 зона попадания мелочи. Снаряды бьют по 1|4|16, лучи обзора — по 1.
- Урон: `take_damage(урон, точка, направление, вид, кто)`; вид "" / "explosion" / "beam".
- Постройки повёрнуты к врагу — их детали поворачивать в мировых координатах.
- Всё, что может выдать врага в тумане, показывать только при `seen` или своей команде.
- Звук в мире — `Sfx.play_at(звук, позиция, громкость, разброс)`, интерфейса — `Sfx.play`.
- Эффекты — из кирпичиков fx.gd (`Fx.beam_material`, `Fx.place_beam`, `_emit`). Яркость держать цветом, не энергией.
- Растягивать предмет по его осям: `basis * Basis.from_scale(...)`, не `Basis.scaled()` (тянет по осям мира).
- Склейка: каждый кусок сначала в модель с таблицей вершин (`Art._indexed`), иначе коробка пропадёт.
- Новые материалы карты — через `vision.register_material`.
- Сломали стену → `main._on_wall_destroyed` (проходимость, туман, миникарта).
- Укрытие может быть повёрнуто (7-е поле, градусы): точка внутри — `Maps.in_box`, рамка по осям — `Maps.box_rect`; не считать укрытия прямоугольниками по осям. Дороги (линии крипов) — только точки `lanepoints`, турели на путь не влияют.
- Новый контроль/статус из абилки — добавить в `Mech.control_info` и `Mech.status_list`.
- Правка файлов Python на Windows — `newline=""`, иначе CRLF на весь файл.

## Как проверять
- Godot: `D:\Godot\Godot_v4.7.2-stable_win64_console.exe` (ниже `godot`). Blender 5.2.2: `D:\SteamLibrary\steamapps\common\Blender\blender.exe` (`-b --python скрипт.py -- аргументы`).
